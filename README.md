## Deploy a Discord bot in four steps

1. Create an application and Bot user in the [Discord Developer Portal](https://discord.com/developers/applications), copy the token and invite the bot to your server.
2. [Create a free ENDHOST account](https://endevil.live/user/register).
3. Create a container, choose Node.js / Python / Ruby / Go / PHP / Bun, upload your code and set the startup command.
4. Press **Start** and watch the logs. Your Discord bot is now hosted 24/7.

## Frequently asked questions

**Is this really free Discord bot hosting?**
Yes. ENDHOST runs your bot in a container on shared infrastructure at no cost. There is no expiring trial and no card required.

**Can I host a Telegram bot too?**
Yes. Telegram bots, Discord bots, web services, APIs, webhook receivers and scheduled jobs all use the same container flow.

**Which programming languages are supported?**
Node.js, Python, Ruby, Go, PHP and Bun. Install dependencies from your existing manifest and point the container at your startup file.

**Do I need a VPS or a server?**
No. You upload code to the panel; ENDHOST runs it in a container. Nothing needs to stay installed or switched on at your end.

**Where do I get support?**
The [Discord community](https://discord.gg/RNVJeMKDAV) is the support desk — setup help, container problems, feature requests and outage notices. The [contact page](https://endevil.live/contact) lists email for private matters.

**Is my bot token safe?**
Tokens and other secrets are encrypted at rest, and the panel never sends a stored token back to the browser. Never paste a token into a public channel or issue — reset it in the Discord Developer Portal if it leaks.
