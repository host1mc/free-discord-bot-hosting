**Discord bots** — discord.py, discord.js, nextcord, disnake, Sapphire, Eris, or any library that runs on a supported runtime.

Node.js, Python, Ruby, Go, PHP and Bun are all supported, with dependencies installed from the manifest you already use (`package.json`, `requirements.txt`, `Gemfile`, `go.mod`, `composer.json`).

## Frequently asked questions

**Is ENDHOST really free?**
Yes. The core hosting is free and supported by ads on the website. There is no trial that expires and no card required.

**Do I need to download or install anything?**
No. You deploy and manage everything from the web panel. We never ask you to disable your antivirus or run an unknown installer.

**Which languages can I use?**
Node.js, Python, Ruby, Go, PHP and Bun. Install dependencies from your existing manifest and point the container at your startup file.

**Can I host a Telegram bot?**
Yes. Use long polling — webhook mode isn't supported.

**Where are my logs and files?**
In the panel. Open the container to see live logs and manage files without a separate FTP client.

**Is my bot token safe?**
Tokens and other secrets are encrypted at rest, and the panel never sends a stored token back to the browser. Never paste a token into a public channel or issue — reset it in the Discord Developer Portal if it leaks.
